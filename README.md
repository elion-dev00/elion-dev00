## 🚀 What I'm building

**[Necto](https://nectoai.app)** is a B2B networking platform for Mexican entrepreneurs, live in production. I'm its sole developer: I took it from a vanilla JavaScript prototype to a full Next.js platform.

- **Stack:** Next.js (App Router), TypeScript, Supabase (PostgreSQL), Vercel, Vercel AI SDK
- **AI-guided onboarding** powered by the Claude API
- **Database security:** row-level security policies, CHECK constraints, enum validation and versioned migrations
- **Passwordless authentication** with magic links, plus role-based access for admins and premium members
- **Transactional email** with Resend (SPF, DKIM and DMARC configured) and bot protection with Cloudflare Turnstile
- **Design system** with reusable components and light/dark themes
- **In progress:** subscription billing with Stripe

> Necto's code is private because it's a live product with real members. I'm happy to walk through its architecture in an interview.
